Welcome to ELMA (Rust Edition)

Thank you for checking out the brand-new elma-rs demo. This build uses Ratatui for the terminal interface and tdoc to render FTML documents.

Try the following while you explore the demo backend:

  • Use the arrow keys to move through mailboxes and messages.
  • Press Tab to cycle focus between the sidebar, list, and viewer.
  • Hit r to refresh the current mailbox.

We hope you enjoy a smoother and friendlier way to triage mail from your terminal. This mock backend ships a handful of sample newsletters and personal messages so you can see how different content renders in the FTML pager.

— The ELMA Team
