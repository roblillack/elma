Ratatui 0.27 Released

We are thrilled to announce Ratatui 0.27, our latest minor release focused on ergonomics and the new renderer API. Highlights include:

  • Unified StatefulWidget rendering with fewer trait bounds.
  • Improved default color palette and better 24-bit color fallback.
  • Cleaner layout helpers and the new Flex widget for gap-aware arrangements.

Read the full announcement for migration tips and code samples.

We want to thank every contributor who helped polish this release. Your feedback and patches make Ratatui a joy to work on.

Happy hacking!
